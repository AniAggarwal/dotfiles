GRUB firmware submenu

Install:
  sudo bash /home/ani/dotfiles/grub-menu/install.sh

Top-level menu:
  Arch Linux
  Advanced options for Arch Linux
  Windows Boot Manager
  UEFI Firmware Settings
  Firmware Boot Options

The last item groups the EFI BootNext entries generated by the installed
GRUB package. The package-owned 31_efi_bootnext script stays intact. A
persistent drop-in suppresses its top-level output; 32_firmware_submenu
calls it with that suppression disabled and wraps its output in a submenu.
Its discovery/filtering logic therefore follows future package updates.
Existing grub-hook kernel-update handling also regenerates this submenu.
Verified on 2026-10-11: the generated menu has exactly five top-level items
and five firmware children. The optional installer argument writes a
readable copy of the installed menu to that specified file.

The installer validates that Linux, Windows and UEFI boot entries retain
their original commands and that all BootNext entries move unchanged.
It does not change the saved default, timeout, EFI NVRAM, or Wi-Fi override.
Windows device numbering in its display label may change between boots;
validation permits that while requiring its UUID and boot commands to match.
If validation fails, it restores the old configuration. The pre-change
configuration is backed up at /boot/grub/before-firmware-submenu.

To undo grouping after later kernel updates, remove both custom files and
regenerate the current menu rather than restoring old kernel references:
  sudo rm /etc/default/grub.d/91_firmware_submenu.cfg /etc/grub.d/32_firmware_submenu
  sudo grub-mkconfig -o /boot/grub/grub.cfg

Opening an entry inside this submenu still uses the package's original
BootNext/reboot behavior. Grouping does not fix a firmware target that
returns to GRUB instead of starting another OS.
